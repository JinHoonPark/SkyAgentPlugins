## 재실행용 pwsh 템플릿

```powershell
$work = Join-Path ([IO.Path]::GetTempPath()) ('skill-trigger-eval-' + [guid]::NewGuid().ToString('N'))
$skill = Join-Path $work 'test-skill'
New-Item -ItemType Directory -Path (Join-Path $work '.claude'),$skill | Out-Null
$utf8 = [Text.UTF8Encoding]::new($false)
$skillMd = @'
---
name: signal-beacon
description: Use when the user asks for the signal beacon skill by name.
---

# Signal Beacon
Return a short greeting.
'@
[IO.File]::WriteAllText((Join-Path $skill 'SKILL.md'), $skillMd, $utf8)
$set = @(
    [pscustomobject]@{ query = 'Use the signal beacon skill to greet me.'; should_trigger = $true }
    [pscustomobject]@{ query = 'What is two plus two?'; should_trigger = $false }
) | ConvertTo-Json -Depth 4
[IO.File]::WriteAllText((Join-Path $work 'eval-set.json'), $set, $utf8)
$homeCommands = Join-Path $HOME '.claude/commands'
$before = if (Test-Path -LiteralPath $homeCommands) { @(Get-ChildItem -LiteralPath $homeCommands -File | Select-Object -ExpandProperty Name) } else { @() }
$oldPy = $env:PYTHONPATH
Push-Location -LiteralPath $work
try {
    $env:PYTHONPATH = Join-Path $HOME '.skywork/skill-trigger-eval'
    python -m scripts.run_eval --eval-set .\eval-set.json --skill-path .\test-skill --runs-per-query 1 --trigger-threshold 0.5 --timeout 60 --model claude-opus-5 > .\result.json 2> .\stderr.log
    $code = $LASTEXITCODE
} finally {
    Pop-Location
    $env:PYTHONPATH = $oldPy
}
$result = Get-Content -LiteralPath (Join-Path $work 'result.json') -Raw | ConvertFrom-Json
$stderrText = [IO.File]::ReadAllText((Join-Path $work 'stderr.log'))
$remaining = if (Test-Path -LiteralPath (Join-Path $work '.claude/commands')) { @(Get-ChildItem -LiteralPath (Join-Path $work '.claude/commands') -File) } else { @() }
$after = if (Test-Path -LiteralPath $homeCommands) { @(Get-ChildItem -LiteralPath $homeCommands -File | Select-Object -ExpandProperty Name) } else { @() }
$added = @($after | Where-Object { $_ -notin $before })
"exit=$code summary=$($result.summary | ConvertTo-Json -Compress) warning=$($stderrText -match 'Warning: query failed') tempCommands=$($remaining.Count) homeNewCommands=$($added.Count)"
if ($code -ne 0 -or $result.summary.total -ne 2 -or $stderrText -match 'Warning: query failed' -or $remaining.Count -ne 0 -or $added.Count -ne 0) { throw "Evaluation check failed; inspect $work" }
$resolved = [IO.Path]::GetFullPath($work)
$tempRoot = [IO.Path]::GetFullPath([IO.Path]::GetTempPath()).TrimEnd('\')
if (-not $resolved.StartsWith($tempRoot + '\', [StringComparison]::OrdinalIgnoreCase)) { throw "Unexpected temp path: $resolved" }
Remove-Item -LiteralPath $resolved -Recurse -Force
```

## 실제 검증

### 이전 Windows 실행 검증

- 격리 경로: `C:\Users\magedoga\AppData\Local\Temp\skill-trigger-eval-60a9090f1ea440fe828d9501921a9425`. 내부의 빈 `.claude/`, 최소 `SKILL.md`, 발동 기대 1개와 비발동 기대 1개인 JSON을 생성했다.
- 실행: 격리 경로를 cwd로 하고 `PYTHONPATH=$HOME/.skywork/skill-trigger-eval`을 설정한 뒤 `python -m scripts.run_eval ... --model claude-sonnet-5 > result.json 2> stderr.log` 명령 실행. `claude -p`는 질의당 1회, 총 2회.
- 문법: `python -m py_compile` 종료 코드 0. 평가: 종료 코드 0, JSON 파싱 성공, `summary={"total":2,"passed":2,"failed":0}`, 결과 2개.
- stderr 비어 있음. `Warning: query failed` 없음. 격리 `.claude/commands/` 잔여 파일 0개. 사용자 홈 `~/.claude/commands/` 실행 전후 파일 0개.
- 확인 후 생성한 격리 디렉터리를 삭제했고, 사본의 실행 중 생성된 `__pycache__/`도 삭제했다.
- 발동 정답 여부는 이전 Windows 실행 합격 판정에 사용하지 않았다.

### 재작업 검증

- 실행: 위 템플릿과 같은 격리 방식으로 빈 `.claude/`, 최소 스킬, 발동 기대 1개·비발동 기대 1개를 만들고 `--model claude-opus-5`로 실행했다. `claude -p`는 총 2회 호출했다.
- 결과: 종료 코드 0, JSON 파싱 성공, `summary={"total":2,"passed":2,"failed":0}`. 발동 기대 질의 `triggers=1/1`, 비발동 기대 질의 `triggers=0/1`로, 프로젝트의 임시 명령이 격리 설정에서도 평가 세션에 보였다.
- stderr 비어 있음. `Warning: query failed` 없음. 격리 `.claude/commands/` 잔여 0개, 사용자 홈 `~/.claude/commands/` 새 파일 0개.
- 격리 경로 `C:\Users\magedoga\AppData\Local\Temp\skill-trigger-eval-c760e16de41f4a949e0138b1ccdf9740`은 `Remove-Item`이 도구 정책으로 거부되어 남아 있다.

## 다른 Windows 문제

이번 영문 테스트에서는 추가 Windows 비호환을 발견하지 못했다. `ProcessPoolExecutor`의 진입점 가드는 원본에 이미 있다. Python 기본 인코딩은 `cp949`로 확인했으며 비 ASCII 스킬 설명·질의는 이번 실행에서 검증하지 않았다.

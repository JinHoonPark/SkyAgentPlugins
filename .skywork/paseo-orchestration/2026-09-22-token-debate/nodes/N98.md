# N98 — sky-agent-plugins GitHub 출처 복원

## 결론

Claude와 Codex의 `sky-agent-plugins` 마켓플레이스 출처를 `https://github.com/JinHoonPark/SkyAgentPlugins.git`로 복원했다. Claude `settings.json` 선언과 `known_marketplaces.json` 출처, Codex `config.toml` 출처가 일치한다. 설치 목록은 전후 ID·enabled·version이 모두 같다. 플러그인 install·uninstall·update는 실행하지 않았다. `N97.failure.md`는 수정하지 않았다.

## 설정 파일의 전후 원문

`~/.claude/settings.json:154-159`의 `extraKnownMarketplaces.sky-agent-plugins`만 변경했다. 변경 전:

```json
    "sky-agent-plugins": {
      "source": {
        "source": "directory",
        "path": "/Users/magedoga/Projects/SkyAgentPlugins"
      }
    }
```

변경 후:

```json
    "sky-agent-plugins": {
      "source": {
        "source": "git",
        "url": "https://github.com/JinHoonPark/SkyAgentPlugins.git"
      }
    }
```

정확히 한 번 일치하는 기존 문자열만 치환했고, 치환 전후 다른 JSON 값이 같은지 확인했다. 수정된 파일을 다시 읽어 같은 문자열임을 확인했으며 JSON 파싱에 성공했다.

`~/.claude/plugins/known_marketplaces.json`의 `sky-agent-plugins` 항목:

| --- | --- | --- | --- |
| 전 | `{"source":"directory","path":"/Users/magedoga/Projects/SkyAgentPlugins"}` | `/Users/magedoga/Projects/SkyAgentPlugins` | `2026-09-24T04:11:23.594Z` |
| 후 | `{"source":"git","url":"https://github.com/JinHoonPark/SkyAgentPlugins.git"}` | `/Users/magedoga/.claude/plugins/marketplaces/sky-agent-plugins` | `2026-09-25T07:08:35.689Z` |

`~/.codex/config.toml:57-59`의 `[marketplaces.sky-agent-plugins]`:


# 화면 양식

## 질문

`{프로필 번호}`는 이번 배치에서 몇 번째 프로필인지, `{진행 표시}`는 작업·모델·생각 능력 세
구간 중 현재 위치를 `n/3`으로 쓴다(표시 색을 묻는 질문에는 붙이지 않는다). `{질문 문구}`는
지금 묻는 항목을 그대로 쓴다 — 어떤 작업을 맡기고 싶은가 / 어떤 모델로 / 생각 능력은.

`{선택지 목록}`은 `  {번호}) {provider} / {모델 ID}      {등급 라벨}` 한 줄씩, 조회 결과
(활성 provider의 모델, 그 모델의 thinkingOptions)에서 나온 값만 1번부터 순서대로 매겨
개수만큼 적는다. 예시의 값을 그대로 옮기지 않는다.

```text
[프로필 {프로필 번호}] {진행 표시} · {질문 문구}

지금 연결된 모델입니다.
{선택지 목록}

번호로 답하시거나 다른 모델 이름을 적어 주세요.
```

## 프로필 확인

`{프로필 번호}`는 이번 배치에서 몇 번째 프로필인지다. `{id}`·`{name}`은 1턴 답에서 자동
파생한 값이다. `{provider}`·`{모델 ID}`는 2턴에서 고른 모델, `{생각 능력}`은 3턴에서 고른
thinkingOptionId다 — 그 모델에 옵션이 없어 필드를 넣지 않았으면 `해당 없음 (이 모델은
옵션이 없음)`을 대신 적는다. `{권한 등급 설명}`은 그 등급이 허용하는 동작을 평문으로 먼저
쓰고, 원시 `{modeId}` 값은 괄호로 보조한다. `{icon}`·`{color}`는 자동 파생 아이콘과 사용자가
고른 표시 색이다. `{notes}`는 줄이 길어도 접지 말고 전부 보이고, 끝에 `({글자 수}자)`를 붙여
160자 한도를 눈으로 확인시킨다.

```text
[프로필 {프로필 번호}] 확인

  id · name    {id} · {name}
  모델         {provider} / {모델 ID}
  생각 능력    {생각 능력}
  권한 등급    {권한 등급 설명} (modeId: {modeId})
  표시         {icon} / {color}
  notes        {notes} ({글자 수}자)

이대로 둘까요? 고칠 것이 있으면 필드 이름을 적어 주세요.
```

## 값 변경 확인

`changes.remove`의 각 항목(id `X`)은 `changes.add`·`changes.replace`의 id 목록과 대조해
바뀐 종류를 정한다. `add`·`replace`는 id만 담으므로 새 값은 방금 제출한 배열에서 찾는다.

- `X`가 `changes.replace`에 있다 → id는 그대로고 값이 바뀌었다. 필드가 빠졌으면 **필드만
  제거**, 필드는 그대로인데 값이 다르면 그 필드명과 새 값을 적는다.
- `X`가 `changes.add`의 새 id 아래 같은 값으로 있다 → **id만 변경**이다.
- 둘 다 아니다 → 같은 값이 배열에 그대로 남아 있다는 뜻이니 **값 동일**로 적는다.

`{대상별 한 줄 목록}`은 위 판정으로 바뀐 프로필마다 `- {프로필명} ({바뀐 내용})` 한 줄로,
`{대상 건수}`만큼 빠짐없이 적는다. `{바뀐 내용}`은 위 판정 결과("id만 변경", "필드 1개
제거" 등)를 옮긴다. `{남는 건수}`는 `changes.finalArrayLength` 값이다.

```text
값 변경 확인 — 사라지는 프로필은 없습니다. id·필드 값만 바뀝니다.

바뀌는 프로필 {대상 건수}건:
{대상별 한 줄 목록}

남는 프로필: {남는 건수}건 (기존과 동일)

이대로 적용할까요?
```

## 삭제 확인

`{대상별 한 줄 목록}`은 사라질 프로필마다 `- {프로필명} ({provider} / {모델 ID})` 한 줄로,
`{대상 건수}`만큼 빠짐없이 적는다. `{대상 건수}`는 직전에 확인한 기존 건수에서
`changes.finalArrayLength`를 뺀 값이고, `{남는 건수}`는 `changes.finalArrayLength` 값이다.

```text
⚠ 삭제 확인 — 되돌리려면 백업 복원이 필요합니다.

사라질 프로필 {대상 건수}건:
{대상별 한 줄 목록}

남는 프로필: {남는 건수}건

정말 진행할까요? "삭제" 라고 답해 주셔야 실행합니다.
```

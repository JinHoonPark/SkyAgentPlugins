# 실패 시

작업을 완료하지 못했으면 **실패 보고 경로**에 실패 사유를 쓴다. 리더가 그 파일만 보고
실패 여부를 판정할 수 있어야 한다. 수정 대상 파일에는 실패 문구를 쓰지 않는다 — 그 파일이
곧 결과 파일이다. 파일 기록이 불가능하거나 사용자가 쓰기를 금지한 경우, 파일 기록을 포기하고
짧은 응답으로 실패와 미검증을 보고한다.

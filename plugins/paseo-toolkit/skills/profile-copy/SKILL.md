# Paseo 에이전트 프로필 전달

Paseo 프로필을 다른 PC로 옮길 수 있도록 `daemon.agentProfiles` 배열을 JSON 코드블록으로
출력한다. 이 작업은 현재 PC의 설정을 **읽기만** 한다. 설정 파일을 바꾸거나 Paseo 데몬을
재시작하지 않는다.

## 입력 확인

1. 사용자 홈 디렉터리 아래 `.paseo/config.json`을 읽고 `daemon.agentProfiles` 배열을 찾는다.
   사용자 홈 경로는 실행 환경에서 구한다. 사용자 이름, 드라이브 문자, 절대 경로를 추측하거나
   하드코딩하지 않는다.
2. 배열이 없거나 JSON을 읽을 수 없으면 코드블록을 만들지 말고, 읽기 실패 사실과 사용자가
   확인할 위치만 알린다. 빈 배열이면 빈 배열을 그대로 출력한다.
3. 배열의 각 객체와 그 안의 `notes`는 원본 그대로 복사한다. 객체를 새로 조립하거나 필드를
   정렬하지 않는다. `id`, `name`, `icon`, `color`, `provider`, `model`, `modeId`,
   `thinkingOptionId`, `notes`의 존재 여부와 값, 그리고 존재할 때의 `featureValues`를 모두
   보존한다. `color`나 `modeId`가 없는 객체에 값을 보충하지 않고, `featureValues`가 없는
   객체에 빈 값을 넣지 않는다.

## 출력

응답은 `json` 코드블록 하나뿐이고, 그 안에는 설정에서 읽은 `daemon.agentProfiles` 배열
원문만 들어간다. 필드 추가·삭제·순서 변경·값 가공은 하지 않으며 `notes`도 고치지 않는다.

코드블록 앞뒤로 제목, 설명, 요약, 특이사항, 아이콘 매핑, 수신자용 지시, 후속 질문을 비롯한
어떤 텍스트도 붙이지 않는다. 위 「입력 확인」의 읽기 실패를 알리는 경우만 예외다.
